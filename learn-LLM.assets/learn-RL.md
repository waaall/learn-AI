# 问题


## 基础问题


### 强化学习和监督学习的本质区别

强化学习不也一样是根据输出和期望的输出的损失函数来修改参数的过程吗？这和监督/自监督学习不是本质一样吗？具体在训练过程中，他们有哪些不一样吗？

有一半是对的：从“优化器在做什么”这个层面看，监督学习、（自）监督学习、强化学习最后都可以写成某个期望目标的最小化或最大化，然后用梯度下降一类方法去更新参数。把强化学习的目标写成最大化期望回报 
$$J(\theta)=\mathbb{E}[\sum_t \gamma^t r_t]$$

也完全可以定义一个“损失” $L(\theta)=-J(\theta)$ 来做梯度下降。但它们在训练过程中有几处本质差异，导致强化学习不能简单等同为“有期望输出的监督学习”。

#### 一 监督或自监督的“目标”是静态的，强化学习的“目标信号”通常是动态的  

1 监督学习 supervised learning 

每个样本有明确标签 y。训练时损失一般是模型输出与标签的差异，比如交叉熵或均方误差。这里的“期望输出”是外部给定的，固定不变。

2 自监督 self-supervised learning 

本质仍是监督，只是标签由数据本身构造出来（mask 预测、对比学习中的正负样本关系、下一个 token 等）。目标同样是静态的：给定输入，伪标签的生成规则不依赖你当前策略去和环境交互。

3 强化学习 reinforcement learning 

你通常没有“正确输出动作”的标签。只有奖励 r（往往是稀疏、延迟的标量），而且你关心的是长期回报，不是某一步动作对不对。更关键的是：很多 RL 算法里训练用的“目标值”本身依赖当前模型的估计（bootstrapping）或依赖当前策略采样到的轨迹分布，因此目标是会移动的。  

典型例子：Q 学习/TD 学习用的目标类似  
$target = r + γ max_a' Q(s',a')$
这个 target 右边的 Q 也是你正在训练的网络或其延迟副本，随着参数变化 target 也在变。这和监督学习的固定标签 y 很不一样。

#### 二 数据分布 i.i.d 与否，以及“模型会改变数据来源” 

1 监督/自监督常见设定  
你面对一个相对固定的数据集，通常近似当作独立同分布 i.i.d 抽样。训练过程不会改变数据集本身的分布（最多改变你采样权重）。

2 强化学习常见设定  
数据是你用当前策略去环境里“采”出来的。你怎么探索、怎么选动作，会直接改变你之后能看到的状态、奖励和轨迹，也就改变了训练数据分布。于是出现两个后果：  
第一，分布是非平稳的 non-stationary：策略变了，数据分布也变。  
第二，样本强相关：轨迹序列在时间上相关，不是 i.i.d。很多稳定化技巧（经验回放 replay buffer、目标网络 target network、on-policy/off-policy 区分）都在处理这个问题。

#### 三 信用分配 credit assignment 的结构不同  

1 监督/自监督  
误差信号大多是“这条样本的输出该是什么”，损失直接对应到当前输出。

2 强化学习  
奖励可能隔了很多步才出现，你需要判断“之前哪些动作对最终奖励有贡献”。这叫时间上的信用分配（temporal credit assignment）。因此 RL 的学习信号往往是  
价值差分 $TD error（r + γV(s') − V(s)$  
或优势函数 $advantage A(s,a)=Q(s,a)−V(s)$
来把延迟回报变成可学习的局部信号。这个结构在监督学习里通常不存在。

#### 四 梯度是怎么来的：监督是“直接可微的监督误差”，RL 常用“估计器”  

1 监督/自监督  
损失对参数的梯度直接由计算图反向传播得到，方差相对小。

2 强化学习  
如果环境动力学不可微或你不去建模环境，策略参数影响回报要通过采样来估计。  
策略梯度 policy gradient 的核心形式是用似然比技巧（log-derivative trick）得到的梯度估计，形如  $$∇θ J(θ) ≈ E[ ∇θ log πθ(a|s) · (return 或 advantage) ]$$  
它不是“输出和标签的差异”那种直接监督误差，而是带有较大采样方差的随机估计，所以会非常依赖基线 baseline、优势估计、critic 等降方差手段。

#### 五 训练流程上的直观区别

1 监督/自监督的典型 loop  
从数据集中取一个 batch  
前向得到输出  
用固定标签或伪标签算 loss  
反向传播更新参数  
循环

2 强化学习的典型 loop  

用当前策略与环境交互采样若干轨迹（探索在这里发生）  
把转移 (s,a,r,s') 存起来或直接用来更新  
计算学习目标（可能用 bootstrap、目标网络、优势估计等）  
更新策略和/或价值网络  
策略变了，再去采新数据  
循环

什么时候它们看起来会“很像”  

当你把 RL 的某一步更新写成最小化一个平方误差（比如 TD error 的均方）时，形式上确实像监督学习：网络输出一个 Q 或 V，target 像“标签”。但关键差别仍然在于：  
target 不是外部真值，而是由奖励加上你当前估计构成，并且数据分布由策略决定、随训练变化。  
因此 RL 比监督学习更容易不稳定，且更依赖算法结构与训练技巧。
