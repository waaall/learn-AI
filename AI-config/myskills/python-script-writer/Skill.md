
# Python script writing Guide


## 核心原则

1. **不硬编码**：路径、参数、数据源、阈值、开关都写入 `config.json`，并支持命令行参数覆盖。
2. **脚本文件头中文注释**：简要描述 功能、整体逻辑、使用方式。
3. **关键代码中文注释**：在核心流程、关键判断、易错点处写简短中文注释。
4. **模块化**：不要一个函数写到底；按“配置/IO/处理/输出/日志”拆分。
5. **日志**：使用python 官方 logger ，在关键步骤给出log信息，并同步保存为 `.log`文件。
6. **依赖与虚拟环境**：如果用到三方库，README 必须包含 venv 创建与安装步骤，同时生成 `requirements.txt`。
7. **README**：环境创建、运行方式、配置字段解释、项目结构说明。
